## Task

Make **`GabClient` Grok-safe** on the shared OpenAI-compatible path: chat/completions request shape, models listing, credits, tools/stream defaults. No greenfield client rewrite; deepen existing `ModelProvider`-aware behavior.

1. **Request construction (`buildJsonChatRequest`)**
   - Compare Grok vs Gab vs Local LLM payloads.
   - For `ModelProvider.GROK`:
     - Must be standard OpenAI-compatible chat body (model, messages, stream, optional tools/`tool_choice`)
     - Must **not** emit Local-only fields (`localllm` preset, forced small `max_tokens`)
     - Must not emit Gab-only fields if any exist that xAI would reject (audit body + headers)
   - Keep Gab and Local LLM behavior working.

2. **Credits / models / tools**
   - `getCredits` already early-returns when `!provider.supportsCredits` — keep Grok skipping credits; ensure UI/callers tolerate null.
   - `listModels` must work against `https://api.x.ai/v1/models` when provider is GROK (no Gab path assumptions in URL/auth).
   - Tools + stream remain enabled for Grok where the shared path supports them (do not disable tools for Grok).

3. **Constructor / call-site hygiene**
   - Default `GabClient` provider is `GAB_AI` — confirm production call sites use `settings.createClient(provider)` (or explicit GROK).
   - If any code constructs `GabClient(key)` without provider while intending Grok, fix those sites (only files in Edit only unless a one-line fix outside is required for correctness — note it in report).

4. **Tests (`GabClientJsonTest`)**
   - Add assertions for `GabClient(..., ModelProvider.GROK)` request JSON:
     - includes tools/`tool_choice` when tools provided
     - does **not** include `localllm` or Local-only `max_tokens`
     - stream flag honored
   - Keep existing Gab/Local tests green.

**Out of deep scope for this order (section-02/03):** SSE delta accumulation, finish_reason taxonomy, AgentSession exit logic — only touch GabClient if a **request-shape** bug for xAI is proven.
