### 3. Fail-not-empty-success + Stop/abort

**Read and verify** (edit only if a gap is proven):

- Non-2xx on chat completions → `GabApiException` with HTTP status (and body retained on exception) — never return empty content as success.
- SSE `error` events → fail completion (throw), not empty success.
