2. **`ModelCatalog` Grok catalog**
   - Review default (`GROK_DEFAULT_MODEL_ID`), `GROK_FALLBACK_MODEL_IDS`, and preferred order against current product intent (default remains `grok-4.3` unless you have a clear reason to change — **document any deliberate model id updates** in Worker report).
   - Ensure `isGrok` / `belongsToProvider` / `filterForProvider` / `sortForDisplay` / `resolveSelection` / `fallbackAsModelInfo`:
     - Keep valid xAI models visible for GROK
     - Do not include Gab-only models in Grok list (and vice versa)
     - Do not break Local LLM filtering

3. **`WarywayGabSettings` routing**
   - Prove `createClient(ModelProvider.GROK)` uses **Grok PasswordSafe key** + **Grok base URL** (never Gab key/base URL).
   - Prove `getApiKey` / `setApiKey` / `getDefaultModel` / `getLastUsedModel` / `hasApiKey` are provider-scoped for GROK vs GAB_AI.
   - Fix any path where active provider or model id could silently swap credentials between Grok and Gab.

4. **Tests**
   - Extend `ModelCatalogTest` (and add a small settings/routing unit test only if feasible without full IntelliJ harness) for:
     - Grok default + fallback order
     - `belongsToProvider` / filter isolation Grok vs Gab vs Local
     - `ownedBy=xai` models counted as Grok even without “grok” in id (if API returns such)
     - Any contract you change
