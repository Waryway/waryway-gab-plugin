## Task

Make **cancel and timeout** on the Local LLM `/api/agent` poll loop reliably testable and correct:

1. **`cancelActiveRun` / user Stop** — marks cancelled, posts `cancelRun` for the active id when present, and the poll loop exits via finish with non-blank final content (user-stop / cancelled path). Does not leave session conceptually “running” (`activeRunId` cleared on finish).
2. **Timeout** — when deadline exceeded: best-effort `cancelRun`, log/onLogLine distinct message, throw `LocalLlmAgentSession.AgentTimeoutException` with message containing timeout wording (not a generic HTTP connection error).
3. **Cancel failure resilience** — if `cancelRun` throws, still exit cleanly with non-blank terminal content (existing try/catch pattern; cover with test).
4. **Test seam** — introduce a minimal mockable surface so tests do not hit real HTTP:
   - Prefer a small interface (e.g. start/get/cancel) implemented by `AgentClient`, **or** constructor-injected functional deps, **or** package-visible overridable hooks — keep change small.
   - Do **not** rewrite AgentClient HTTP stack.
5. **Unit tests** in `LocalLlmAgentSessionTest` (and `AgentClientTest` only if cancel/parse edge needs a contract test):
   - Mid-run cancel → Result with non-blank content; state cancelled or user-stop path
   - Timeout → `AgentTimeoutException`; cancel invoked
   - Immediate terminal start (isTerminal on start) still finishes via finish path
6. **LOCAL_LLM-only** — do not add any GROK_BUILD / cloud path into `AgentClient` or `LocalLlmAgentSession`. Document in summary that routing gate remains tool-window `provider == LOCAL_LLM && agentMode` (read-only verify).

Coordinate with **wo-03-01**: use pure finish/status helpers if already present; if concurrent, do not re-implement finish string logic — call existing private/companion helpers or leave finish body intact and only add the run-loop seam + tests.

If Stop wiring in `WarywayGabToolWindowPanel` is clearly broken (`activeLocalAgent.cancelActiveRun` not called), fix **only** that cancel/Stop line region — otherwise leave the panel alone.
